# 科科打牌记分器

一个简洁的移动端打牌（3–6 人）记分工具，纯前端单页应用，无需后端，支持离线使用。

![demo](demo.gif)

## 功能特性

- **3–6 位玩家**：统一深色头像底板，可使用 emoji、字母或一两个中文作为身份标记
- **滚轮输入分数**：每人通过拖动滚轮选择本轮得分（人数越多，可选范围越大）
- **自动补全**：当只剩 1 位玩家未拨分时，自动计算最后一人的分数（确保总和为 0）
- **分数校验**：提交前检查所有玩家分数之和是否为 0，否则给出提示
- **历史记录**：固定列宽展示每轮得分和每位玩家的本轮角色称号，默认显示最近 5 轮
- **撤销**：可撤销最近一轮的提交
- **牌桌设置**：头像昵称、音效、新局和帮助统一收进右上角三点设置
- **本地持久化**：游戏状态存储于 `localStorage`，刷新后恢复
- **原位结算播报**：筹码直接从失分玩家行流向赢家，总分逐级滚动并吸收本轮分差；随后赢家称号从头像位置放大、盖章锁定再收回
- **中文称号**：识别双响连捷、三连制霸、天下无双、绝境翻盘、超神一击和炸弹累计表现
- **个人战报**：点击头像查看当前排名、胜场、最高得分及每轮称号历史
- **排名头像**：前三名头像显示金、银、铜小皇冠与对应光效，上一轮唯一赢家另盖红色“胜”章；新局未开张时不显示虚假排名
- **炸弹模式**：指定赢家后统一向其他玩家收取 2 分或 4 分，点击后直接结算并单独记录
- **可选音效**：结算音效默认关闭，可在牌桌设置中试听；开启后包含强化音效与中文称号播报
- **移动端优化**：触屏友好，支持 iOS Safe Area，深色主题

## 使用方法

直接访问在线版本即可，无需安装任何依赖：

- 主入口：[https://pkscore.netlify.app/](https://pkscore.netlify.app/)
- 备用入口：[https://lingceng.github.io/scorecard/](https://lingceng.github.io/scorecard/)
- 微信小程序：搜索「科科打牌记分器」

## 规则说明

每轮结束后，各玩家拨动对应滚轮选择得分，**所有玩家分数之和必须为 0**，然后点击「提交分数」。
若只剩 1 位玩家未拨分，系统会自动高亮并填入对应值。

## 技术栈

- 原生 HTML / CSS / JavaScript（无框架、无构建工具）
- `localStorage` 持久化
- Google Fonts（DM Mono + Noto Sans SC）
