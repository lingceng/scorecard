# 双端体验基线

网页版是快速试验场，小程序在规则、信息层级与视觉语义上保持一致，但优先采用微信原生能力，不逐像素复制。

## 共同规则

- 3–6 人、每轮总和必须为 0，最后一位未输入玩家可自动补分，全 0 不可提交。
- 头像统一深色底板，身份标记支持 emoji、字母或 1–2 个中文字符。
- 历史记录固定玩家列；炸弹记录类型和倍率；稀有称号只在关键表现出现。
- 排名前三使用金、银、铜皇冠；上一轮唯一赢家保留透明单圈“胜”章。
- 称号判定以 `shared/game-rules.js` 为唯一规则来源，展示层不自行猜测。
- 结算遵守“筹码流转 → 数字滚动 → 稀有称号全局出现并落位”的因果顺序。
- 动效不缩放头像；音效默认关闭；减少动态时直接更新结果。

## 平台差异

| 能力 | 网页版 | 微信小程序 |
| --- | --- | --- |
| 顶部设置 | 自定义右上角按钮 | 避开微信胶囊，使用内容区“牌桌”入口 |
| 分数滚轮 | 自定义可访问滑杆 | 原生 `picker-view` / `picker-view-column` |
| 触觉反馈 | 不提供 | 滚轮落位轻震，提交中震 |
| 分享 | Web 链接 | 原生分享好友 / 朋友圈 |
| 音频 | Web Audio + 本地短音频 | `InnerAudioContext` + 包内同源短音频 |
| 弹层 | HTML dialog/sheet | 原生交互优先，复杂内容使用底部 sheet |

## 同步方式

`scorecard/shared` 是规则和体验文档的源目录。执行 `node scripts/sync-mini-shared.mjs` 会将规则、体验文档与当前仍在使用的音频复制到同级 `scorecard_mini`；`--check` 只检查差异，不写文件。生成副本需要与两端代码一起提交。
